An AI agent launches a real coin on pump.fun (Solana) fully autonomously — the make.fun ghost mascot as its logo, unmodified from the press kit — and this program hands the launch record (the coin's mint and its create transaction signature, in LAUNCH.json) to the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
